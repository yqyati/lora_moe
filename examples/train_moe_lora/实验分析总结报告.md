# MoE-LoRA 实验分析总结报告

## 一、研究概述

本研究在 MoE Transformer（OLMoE-1B-7B）主干上引入 LoRA 分支，核心创新点：

1. **路由压缩投影（Routing Projection）**：LoRA 的路由不独立学习，而是直接复用 MoE router 的输出，通过投影矩阵 W 压缩得到：`p_L = softmax(W · router_logits)`
2. **全局共享 LoRA 池（Global Shared Pool）**：所有层共享一个 LoRA expert 池，各层通过独立的投影矩阵 W 选择不同的 expert 子集

对比方法：
- **Baseline2（Independent Routing）**：LoRA 路由通过独立的 gate 网络从 hidden state 学习，不复用 MoE router 信息

---

## 二、当前实验结果

### 2.1 GSM8K 性能对比

| 方法 | 路由方式 | 池结构 | GSM8K 准确率 |
|------|---------|--------|-------------|
| Base (无 LoRA) | - | - | ~0.10 |
| Baseline2-per_layer | independent | 16 experts/layer | ~0.33 |
| Baseline2-global | independent | 256 experts (global) | **~0.36** |
| V2 (Ours) | projection | 128 experts (global) | ~0.33 |

**现状**：Baseline2-global 性能领先我们的方法约 3 个百分点。

### 2.2 性能差距的可能原因

1. **路由信号维度瓶颈**：MoE router logits 仅 64 维（= MoE expert 数），要投影到 128/256 维的 LoRA pool 空间，信息不足
2. **Independent router 容量更大**：从 2048 维 hidden state 直接学习，信息量远超 64 维 router logits
3. **投影矩阵 W 的表达力限制**：线性投影可能不足以捕获 hidden state 中与 LoRA 路由相关的全部信息

## 三、分析实验结果

尽管在绝对性能上暂时落后，我们的方法在以下维度展现出独特优势：

### 3.1 路由对齐度分析（Routing Alignment）

**实验设计**：对比 V2（projection）和 Baseline2（independent）的 LoRA routing 与原始 MoE routing 的对齐程度。

| 指标 | Ours (Projection) | Baseline (Independent) | 含义 |
|------|-------------------|----------------------|------|
| **F-statistic** | **47.29** | 15.51 | MoE 分组对 LoRA routing 方差的解释力 |
| RSA 相关系数 | 0.3189 | 0.2749 | 路由空间结构一致性 |
| 归一化互信息 (NMI) | 0.0212 | 0.0116 | MoE routing 对 LoRA routing 的预测力 |
| 条件熵 H(LoRA\|MoE) | 3.8502 | 4.8640 | 已知 MoE routing 后的剩余不确定性 |

**核心结论**：

- **F-statistic 差异 3 倍**：被同一 MoE expert 处理的 token，在我们的方法中被路由到高度一致的 LoRA expert；Baseline 的 LoRA routing 与 MoE 分组关系弱得多
- **条件熵低 1.01**：知道 MoE routing 后，我们方法的 LoRA routing 几乎可预测；Baseline 仍有高不确定性
- **保留了预训练知识**：projection 方法成功继承了模型在预训练阶段学到的 expert 分工结构

**逐层规律**：
- 高对齐层（Layer 0, 1, 5, 6, 7, 15）：RSA 达 0.5-0.67，MoE 信号被充分利用
- 低对齐层（Layer 2-4, 8-14）：这些层可能需要独立于 MoE routing 的信息
- 提示：可设计 layer-adaptive routing（高对齐层用投影，低对齐层用独立路由）

### 3.2 全局共享池优势分析（Global Pool Advantage）

**实验设计**：对比 Baseline2-global（256 experts, global pool）和 Baseline2-per_layer（16 experts/layer, per_layer pool），证明全局共享池的结构优势。

#### 跨层路由差异度

| 指标 | Global Pool | Per-Layer Pool | 倍数 |
|------|------------|----------------|------|
| 跨层 cosine 距离 | **0.659** | 0.169 | **3.9×** |

- Global pool 各层选择了显著不同的 expert 子集 → 共享不等于雷同
- Per-layer pool 各层路由模式高度相似 → 独立池反而同质化

#### 路由组合多样性

| 指标 | Global Pool | Per-Layer Pool | 倍数 |
|------|------------|----------------|------|
| 每层不同 pattern 数 | 1,226 | 933 | 1.3× |
| 理论最大组合数 | C(256,4) ≈ 1.75 亿 | C(16,4) = 1,820 | **96,038×** |

- 更大的组合空间让模型能为每个 token 找到更精确的 expert 组合
- 实际利用的 pattern 数多出 31%，验证组合空间确实被有效使用

#### Expert 跨层共享度

| 指标 | Global Pool | Per-Layer Pool |
|------|------------|----------------|
| 在 ≥75% 层活跃的 expert | 6 | 4 |
| 仅在 ≤25% 层活跃的 expert | 3 | 4 |

- 全局池自动分化出"通用型"和"专用型" expert
- 通用 expert 被多层复用 → 跨层知识共享
- 专用 expert 仅服务少数层 → 层特异化分工

#### 参数效率对比

| 维度 | Global Pool | Per-Layer Pool |
|------|------------|----------------|
| 每个 expert 获得梯度信号 | 16× (所有层) | 1× (仅本层) |
| 组合丰富度 | 96,038× | 1× |
| 有效参数利用率 | 高 | 低（碎片化） |

## 四、论文贡献点提炼

### 贡献 1：路由压缩投影（Routing Compression）

> 我们提出从 MoE router 输出中压缩得到 LoRA routing，仅需 0.016M routing 参数/层（vs independent router 的 0.52M），同时保持了与模型预训练 expert 结构 3× 更高的对齐度（F-stat: 47.3 vs 15.5）。

**论文叙事角度**：
- 不是"我们的路由更好"，而是"我们的路由更高效、更结构化"
- 同等参数预算下，routing projection 把参数省下来给了 LoRA expert 本身
- 保留预训练 expert 分工 → 更好的可解释性

### 贡献 2：全局共享 LoRA 池

> 全局共享池实现了跨层知识复用（3.9× 跨层路由多样性），同时自动分化出通用/专用 expert 角色，以固定参数量获得 96,000× 组合空间扩展。

**论文叙事角度**：
- Per-layer 池是碎片化的，每个 expert 只被 1 层可见，梯度信号少
- Global 池让每个 expert 获得 16× 梯度信号，训练更充分
- 性能提升（per_layer → global 约 +3 点）验证了这一理论分析

### 贡献 3：方法论分析框架

> 我们提出了一套完整的 MoE-LoRA 路由分析框架（RSA、F-statistic、条件熵、跨层多样性），为该领域提供了可复用的评估工具。

## 五、当前劣势与改进方向

### 5.1 核心瓶颈：64 维路由信号

MoE router logits 仅 64 维，映射到 256+ 维 LoRA pool 空间时信息不足。

### 5.2 改进方案（按优先级排序）

| 方案 | 思路 | 预期收益 | 实现难度 |
|------|------|---------|---------|
| **残差叠加** | p_L = softmax(W·router_logits + gate(h)) | 补充 hidden state 信息 | 低 |
| **门控融合** | α·projection + (1-α)·independent | 自适应混合两种信号源 | 低 |
| **扩充路由信号维度** | 拼接 router_logits + top-k hidden + 层编码 → 144d+ | 从根本增加信息量 | 中 |
| **MoE-aware 初始化 + 正则** | W 初始化为 MoE→LoRA 映射 + 对齐正则 | 利用预训练先验 | 中 |
| **Layer-adaptive routing** | 高对齐层用 projection，低对齐层用 independent | 结合两者优势 | 中 |

### 5.3 论文策略建议

**策略 A（如果改进后能追上 Baseline2）**：
- 标准叙事：提出方法 → 实验验证 → SOTA
- 需要至少持平或超过 Baseline2

**策略 B（如果差距难以弥合）**：
- 重新定位：分析性论文 + 高效路由
- 强调：routing 参数少 32×、保留预训练结构、全局池设计、分析框架
- 参照 LoRAMoE 的写法：不一定要绝对 SOTA，证明方法有独特价值即可

**策略 C（混合方案）**：
- 用 Layer-adaptive routing 或 Gated fusion 追上 Baseline2
- 同时保留路由对齐、参数效率等分析作为消融实验
- 既有性能又有分析深度
